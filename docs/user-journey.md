# Путь пользователя

Главная → отдельная страница прогноза. Страницы входа, регистрации, восстановления, аккаунта и истории доступны для просмотра; серверные действия отключены до согласования API. Информационные страницы доступны из шапки и footer.

| Этап | Действие пользователя | Обратная связь | Следующее состояние |
|---|---|---|---|
| 1. Знакомство | Открывает MedPredict | Назначение, режим работы, три шага и предупреждение | Переход к форме |
| 2. Переход | Нажимает «Попробовать демо» / «Получить прогноз» | Открывается страница прогноза, фокус H1; «Перейти к форме» фокусирует первое поле | Ввод |
| 3. Подготовка real | Ожидает GET описания модели | Загрузка или ошибка с повтором; без метаданных форма не доступна | Ввод после валидного GET |
| 4. Ввод | Заполняет показатели | Подписи, единицы, обязательность, подсказки из конфигурации | Клиентская проверка |
| 5. Исправление | Отправляет пустые/некорректные данные | Ошибки у полей, связанный aria-describedby, фокус первого проблемного поля | Повторный ввод |
| 6. Отправка | Нажимает кнопку или Enter | Видимое состояние обработки, disabled отправка, aria-busy, отмена | Успех/ошибка/отмена |
| 7. Результат | Изучает ответ | Показатель, значение, единица, версия при наличии, обязательное предупреждение; фокус заголовка результата | Изменение данных |
| 8. Серверная ошибка | Читает сообщение | Ошибки известных полей рядом с ними; общая ошибка для сети, таймаута, 5xx, неизвестного поля/контракта | Повтор без потери ввода |
| 9. Отмена/изменение | Отменяет запрос или меняет поле | Запрос отменяется; прошлый результат исчезает; поздний ответ не отображается | Новый запрос |
| 10. Экспорт | Нажимает «Скачать PDF» после успеха | Подготовка с блокировкой повтора; прямое скачивание, при ошибке повтор экспорта | Текущий результат остаётся на экране |
| 11. Повтор | Нажимает «Изменить данные» | Возврат фокуса к форме, введённые значения сохраняются | Ввод и повторная отправка |
| 12. Очистка | Нажимает «Очистить» | Нативный диалог; отмена возвращает фокус и сохраняет значения; подтверждение очищает ввод, ошибки и результат | Пустая форма |
| 13. Другой экран | Открывает модель, аккаунт или другую страницу | Запрос отменяется, результат сбрасывается; введённые значения и язык остаются в памяти | Возврат к данным без автоматического POST |

На desktop форма и результат рядом; на mobile результат находится сразу после формы. Статус доступен для скринридера. Нативные input/select работают с клавиатуры; после ошибок фокус перемещается на соответствующее поле, после успеха — на результат. Поддерживается `prefers-reduced-motion`.

Ввод числа допускает `27.4`, `27,4`, ноль и отрицательные значения. Пустота не превращается в ноль; буквы, бесконечность, экспоненциальная запись и неоднозначные разделители отклоняются. Пробелы по краям удаляются. Необязательное пустое поле пропускается. min/max/integer применяются только из конфигурации; медицинские диапазоны демонстрационного варианта ещё не определены.

В demo каждый результат — заранее заданный пример. В real отсутствует автоматическое переключение на демонстрационные данные при ошибке. Для повторного запроса данные не нужно вводить заново. Значения не сохраняются после перезагрузки или закрытия вкладки.
