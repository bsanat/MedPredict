# Общие цвета и иконки

Источник палитры — [src/styles/tokens.css](../../src/styles/tokens.css). Локальный макет копирует этот файл при экспорте, поэтому значение каждого токена задаётся один раз. Применены все 17 цветов последнего брифа без изменения значений. Accent `#4BA4A4` имеет недостаточный контраст для обычного текста на белом и используется только как декоративный токен. Логотип сохранён без изменения пикселей.

| Назначение | Токен / цвет |
|---|---|
| Фон / поверхность | `background #FFFFFF`, `surface #F5F7FA` |
| Текст / вторичный текст | `text #20242B`, `text-muted #60656E` |
| Primary / hover / label | `primary #183B78`, `primary-hover #0C215A`, `on-primary #FFFFFF` |
| Декор / его поверхность | `accent #4BA4A4`, `accent-surface #EAF5F5` |
| Разделители / поля | `border #E0E2E6`, `input-border #8A94A3` |
| Ошибка / её поверхность | `error #C0262D`, `error-surface #FFF4F4` |
| Предупреждение / его поверхность | `warning #B45309`, `warning-surface #FFF8EB` |
| Подтверждение / его поверхность | `success #157A4B`, `success-surface #EFF8F2` |

Иконки — один набор [Flaticon Uicons Regular Rounded](https://www.flaticon.com/uicons/get-started/). Векторные контуры извлечены из официального набора; это inline SVG, без иконочного шрифта, PNG, внешних запросов и нового npm-пакета. React загружает только девять используемых значков через общий `Icon`; локальный макет использует те же контуры плюс значки существующих дополнительных сценариев. Геометрия outline сохраняется без дополнительного stroke, чтобы не утолщать готовые контуры. Обычный цвет — `currentColor`.

Размеры: 16px для компактных пояснений, 20px внутри кнопок, 24px для секций и состояний. Маленькая иконка не уменьшает touch target: кнопки остаются не меньше 44px. Число прогноза не получает медицинской цветовой классификации. Сервисные ошибки и отмена нейтральные, input errors красные, подтверждённые действия зелёные.

Авторство указано в footer: Uicons by Flaticon. Условия использования: https://www.flaticon.com/uicons/get-started/#license-summary. Первичный источник контура: https://cdn-uicons.flaticon.com/uicons-regular-rounded/webfonts/uicons-regular-rounded.woff2. Конвертер — временный инструмент, не зависимость приложения.
