# Визуальный макет

[`concept.png`](concept.png) создан встроенным Image Gen как макет главного экрана. Это визуальное направление для прототипа, а не скриншот работающей системы. Все элементы сайта реализованы нативным HTML/CSS/React; изображение не подменяет интерфейс.

Краткий использованный бриф: полный экран MedPredict на русском; белый фон, тёмный текст, спокойный бирюзовый акцент; компактная шапка с видимым деморежимом; заголовок «Данные сегодня. Прогноз на шаг вперёд.»; три шага; форма из пяти предварительных полей слева и пустой результат справа; предупреждение о незавершённом контракте; блок об учебном прототипе; без клинических выводов, регистрации, истории и фиктивных метрик. Планировался размер 1440×1200; фактический размер генерации — 1374×1145, проверен в браузере.

## Дизайн-система

- Фон #ffffff, текст #152d39, акцент #146b60, вторичный текст #526578, границы #d8e1e7, светлый фон результата #f0f9f6.
- Системный sans-serif: нет внешнего запроса к сервису шрифтов.
- Главный заголовок 44 px desktop / 32 px mobile; секции 25 / 21 px; основной текст 14–18 px; поля 15 / 16 px.
- Радиус панелей 16 px, кнопок 13 px, полей 9 px. Один уровень панелей, без вложенных карточек.
- Два столбца рабочего блока 1.6:1; форма с двумя столбцами полей. При ширине 820 px рабочий блок становится одноколоночным, при 480 px поля тоже идут в один столбец.
- Иконки: небольшие линейные SVG для направления, состояния и приватности. Акцентные кнопки, заметный синий фокус, отдельные сообщения ошибок.
- Загрузка использует тот же блок результата; успех показывает число и единицу; ошибка — пояснение и возврат к данным. Движение отключается при предпочтении уменьшенной анимации.

## Уточнения текста при реализации

В макете генератор написал про анализ данных моделью. В интерфейсе третий шаг уточнён до «Посмотрите значение и ограничения прогноза», чтобы не приписывать демо работу нейросети. Текст о целевой аудитории заменён точным указанием на ещё не утверждённый прогнозируемый показатель. Добавлены знак обязательных полей, полная политика клиентского хранения и явное пояснение фиксированного деморезультата. Это необходимые уточнения из задания; информационная архитектура и визуальная система сохранены.

В real подпись приватности меняется на «Данные отправляются серверу для прогноза». Фиксированная подпись «Данные остаются в этой вкладке» применима только к demo. Реальный API, сообщения ошибок и новые поля используют те же компоненты.
