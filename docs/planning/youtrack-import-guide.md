# MedPredict тапсырмаларын YouTrack жүйесіне импорттау

Дайын файл: [youtrack-import.csv](youtrack-import.csv). Негізі — бастапқы предзащита талаптары және [13 тапсырмалық жоспар](tasks.csv). Файлда 13 тапсырма бар; сипаттамалары бастапқы талаптар мен жоба құжаттарына сәйкес орысша дайындалған. CSV кодтауы UTF-8 BOM, бөлгіші үтір; тырнақша мен көпжолды сипаттамалар CSV ережесімен жазылған.

## Қай нұсқа қолайлы

Бұл жұмысқа CSV жеткілікті: формулалар, бірнеше парақ немесе күрделі безендіру қажет емес. XLSX осы 13 тапсырманы импорттауда қосымша мүмкіндік бермейді. YouTrack-тың тексерілген ресми нұсқаулығында **CSV және XLSX файлдары Google Sheets арқылы импортталады**. «CSV» батырмасы компьютердегі файлды тікелей жүктеу мүмкіндігін білдірмейді.

Тексерілген нұсқаулықтар, 16 қазан 2026: [CSV импорты](https://www.jetbrains.com/help/youtrack/cloud/import-from-csv.html), [XLSX импорты](https://www.jetbrains.com/help/youtrack/server/import-from-xlsx.html). Қолданыстағы интерфейс өзгеше болса, келесі қадамдағы нақты нұсқауды басшылыққа алу керек. Осы файлды нақты YouTrack импортерінде іске қосу орындалған жоқ.

## Файлдағы бағандар

| Баған | Мақсаты |
|---|---|
| `Summary` | Тапсырма атауы және жергілікті PLAN нөмірі |
| `Description` | Күтілетін нәтиже, қабылдау критерийі, бастапқы талап, дайындық күйі, жауапты, мерзім және құжаттар |
| `Priority (enum)` | Жоспардағы P0 → Critical; P1 → Normal. Бұл жобаға ұсынылған сәйкестік |
| `Type (enum)` | Барлығы Task |
| `State (state)` | Барлығы Submitted: review/келісу міндеттері аяқталды деп белгіленбейді |
| `Due Date (date)` | Жоспарлы күн, YYYY-MM-DD; интеграцияның мерзімі бос, өйткені ол келесі кезеңге жатады |
| `Planned owner (string)` | Жоспарланған жауаптының аты, мәтіндік өріс; нақты Assignee емес |
| `Plan ID (string)` | PLAN-01…PLAN-13; YouTrack жаңа MED нөмірлерін өзі береді |

Нақты аккаунт логиндері берілмегендіктен, `Assignee (user)` және `Author` бағандары енгізілмеді. YouTrack `user` типіндегі бейтаныс мәнге жаңа аккаунт жасай алады. Импорттан кейін нақты бар аккаунттарды Assignee өрісіне тағайындау керек; мәтіндік жауапты бұл талапты толық орындамайды. `Created`, `Resolved` және жалған орындалған күйлер жоқ. Жоспарланған күндер командамен келісуге жатады.

## Импорт тәртібі

1. Google Sheets ішінде бос кесте ашып, **Файл → Импорт → Жүктеу** арқылы `youtrack-import.csv` файлын таңда. Бөлгіш — үтір. Қазақша/орысша мәтіннің дұрыс көрінгенін тексер.
2. Тапсырмалар парағын **MedPredict** деп ата. Бірінші жол — баған атаулары; одан кейін тура 13 тапсырма болуы керек. Қосымша түсіндірме жолдарын, қорытындыларды және формулаларды қоспа.
3. Ресми импорт жолы кестеге сілтемесі бар адамдарға қарау мүмкіндігін және Google Cloud API key талап етеді. Оны қолданар алдында осы жоспардың мәтіні мен команда аттарының сілтеме арқылы қолжетімді болатынын ескер. Құпия кілтті CSV-ге, репозиторийге немесе чатқа енгізбе. Бұл дайындық барысында ешбір кесте жарияланған жоқ, Google API қосылмады және кілт жасалмады.
4. YouTrack ішінде **Администрирование → Интеграции → Импорты → Новый импорт → CSV** таңда. CSV таңдауы Google Sheets баптауына апарса, кесте URL мен API key сол интерфейсте енгізіледі. Нақты өрістерді өзгерту алдында көрсетілген параметрлерді тексер.
5. Project Mapping қадамында парақты **бар MedPredict / MED жобасына** сәйкестендір. Автоматты түрде басқа жоба құру нұсқасын қалдырма. MED қолжетімсіз болса, импортты бастамай, жобаның бар-жоғын және құқықтарды тексер.
6. Priority/Type/State атаулары мен типтері жобадағы өрістермен сәйкестігін тексер. Файл стандартты жобаның ағылшынша мәндерін қолданады; жоба өрістері орысша болса, алдын ала сәйкес мәндерге ауыстыр немесе импорт конфигурациясында сәйкестендір. Бір атаудағы қайталама өрістер мен жаңа кездейсоқ күйлер жасалмауын тексер.
7. 13 тапсырма және дұрыс жоба көрсетілгеннен кейін импортты баста. Журналдан қателерді және нәтиже санын тексер; PLAN нөмірлерін нақты MED нөмірлерімен байланыстыр.
8. Бар аккаунттардан нақты орындаушыларды тағайында. Әр тапсырмадағы мерзім, басымдық, қабылдау критерийі және құжаттар тексерілсін. Қабылдау орындалмайынша тапсырмаларды жабуға болмайды.

## Импорттан кейінгі тексеру

MED жобасында осы импорттан 13 тапсырма бар; PLAN-01…PLAN-13 бір-бір рет кездеседі; сипаттамалар үзілмеген; 12 мерзім дұрыс, PLAN-11 мерзімі бос; Priority/Type/State өрістері дұрыс типте; жаңа пайдаланушы аккаунттары жасалмаған; нақты орындаушылар тағайындалған; әр міндеттің күтілетін нәтижесі мен қабылдау критерийі бар.

Жаңа импорт конфигурациясымен сол CSV-ді қайта енгізу дубльдерге әкелуі мүмкін. Қайта іске қоспас бұрын қазіргі import job пен MED тапсырмаларын тексер. Бұл CSV құжаттарды Knowledge Base мақалалары ретінде импорттамайды: ол тапсырмалар мен репозиторийдегі материалдарға сілтемелерді дайындайды. Push, нақты импорт және DEMO жобасын өшіру осы файлды дайындауға кірмейді.
