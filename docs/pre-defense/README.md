## 3 Что подтверждено и что предложено

Подтверждены локальный React frontend, явно фиксированный demo, макет Figma и существование указанного GitHub-репозитория. Сообщение команды о разработке backend/ML не является проверкой отсутствующих здесь исходников и артефактов. Новые документы не меняют действующий предварительный GET/POST-контракт.

M1 — числовой target Diabetes, M2 — оценка измеренного САД на NHANES, M3 — прогноз глюкозы на ещё не выбранном продольном наборе PhysioNet. Все три модели и их интеграция остаются будущей работой; горизонт M3 не утверждён. Исследование не сужает официальную тему до одной болезни.

Не подтверждены реальная пользовательская проблема, документ о назначении руководителя, подлинный отзыв, экспериментальное качество, настоящая backend-интеграция, назначенные задачи и вклад всех участников в единой сдаваемой истории. Имеющиеся AI-профили не закрывают эти пункты.

## 4 Формат Word и обновление

Word-файлы используют единые чёрные заголовки, нумерованные разделы, таблицы с повторяемой строкой заголовка, подписи и номера страниц. Широкие таблицы переведены на альбомные A4-страницы. Содержание по разделам предусмотрено для длинных документов. Предоставленный вузовский файл не задаёт шрифт/поля/объём; принятые параметры являются оформлением команды и подлежат замене при получении отдельного шаблона AITU.

Для воспроизведения использовать runtime из Codex workspace dependency loader и команду `python3 docs/pre-defense/tools/build_documents.py`. Скрипт требует bundled python-docx/Pillow и bundled Node marked/sharp; системный Python может не содержать их. `--check` проверяет 11 источников и картинки без записи, `--self-test` выполняет малую самопроверку. После правок Word заново отрисовать и просмотреть; успешная запись DOCX не доказывает отсутствие дефектов вёрстки.

Все прежние документы остаются историческим контекстом. Для сдачи использовать этот индекс, чтобы не смешивать новый трёхмодульный план с прежней предварительной постановкой одного показателя. Порядок commit/PR/тега описан в checklist и требует отдельного разрешения пользователя.
