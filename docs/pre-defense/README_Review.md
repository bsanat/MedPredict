### Материалы первой предварительной защиты

Astana IT University, Software Engineering, SE-2409. Первая предварительная защита — 24 октября 2026 года по плану команды. Официальная тема: «Разработка интеллектуальной системы прогнозирования медицинских показателей на основе нейронных сетей».

Команда: Бөгенбаев Санат Амандықұлы — frontend/UI/UX; Баймен Али Қуанышұлы — данные, обучение и оценка нейросетей; Сеилхан Оралхан Сайранұлы — Java backend, REST API и интеграция. Научный руководитель — Турарова Маржан Кабдыкалиевна; ФИО подтверждено командой 16.10.2026, документ о назначении и отзыв ещё не предоставлены.

Предложены три независимых исследовательских модуля: числовой показатель развития диабета на scikit-learn Diabetes; оценка измеренного систолического давления на выбранных данных NHANES; краткосрочный прогноз глюкозы на подходящем продольном наборе PhysioNet. Это долгосрочный план, модели ещё не представлены в данном репозитории. Набор и горизонт прогноза глюкозы не утверждены. Текущий demo использует фиксированное 134,2 и не выполняет inference.

Комплект Word и Markdown, диаграммы, реальные скриншоты и открытые требования: `docs/pre-defense/README.md`. Актуальная ссылка команды: https://github.com/bsanat/MedPredict . Макет: https://www.figma.com/design/zOkk0fppNrBrjWDblCDwyF/Untitled?node-id=0-1 . Планировщик из прежнего README: https://medpredict.youtrack.cloud/issues/MED ; актуальные назначения и доступ ещё требуется проверить.

Не закрыты первичными свидетельствами: 3–5 реальных обсуждений либо соглашение с заказчиком, документ назначения/отзыв руководителя и исправления, согласование данных/API, задачи YouTrack с исполнителями, вклад всех участников и сдаваемый Git-тег. ### Уточнение запуска

В существующем блоке клонирования после проверки команды заменить старый URL на `git clone https://github.com/bsanat/MedPredict.git`. Ветка локального осмотра — figma-design; перед защитой указывать действительно принятую версию. Не добавлять checkout ещё не созданного тега.
