## Основной и ошибочные пути

- Пустая форма: пять ошибок обязательных полей, фокус первого поля, связанный aria-describedby.
- Числовой ввод: точка/запятая, ноль, отрицательные, дроби, пробелы по краям; отклонение букв, неоднозначных разделителей, Infinity, экспоненциальной записи.
- Демоуспех: фиксированное 134,2, честная отметка демопримера, единицы, версия и предупреждение.
- HTTP-адаптер: точный JSON из примера, 400 у известного поля, неизвестное поле, 503, сетевой сбой, таймаут, неправильные типы/единицы ответа.
- Новый показатель из GET: изменённые поля и единицы без правки компонентов, серверные min/max, настроенная точность результата.
- Повтор: значения сохраняются при ошибке, после исправления запрос успешен.
- Три быстрых requestSubmit: один POST.
- Отмена/изменение во время обработки: результат отменённого запроса не появляется даже после задержки фикстуры.
- Изменение после результата: прежний результат немедленно скрывается.
- Неверные метаданные: форма заблокирована, повтор загрузки работает.
- Сценарии demo validation/unavailable: отдельно проверены на адаптере; отображение соответствующих ошибок проверено E2E через тот же интерфейс API.

## Что пока не проверено

Нет сквозного теста с настоящим Java/Spring Boot и моделью, подтверждения GET-контракта, датасета, медицинских диапазонов, клинической/исследовательской точности. Desktop/mobile размеры проверены в браузерах, но физические телефоны, скринридеры, Firefox и реальный HTTP-путь в Safari не тестировались. Это ограничение проверки, а не утверждение совместимости. Нативный desktop-select в headless Chromium на macOS остаётся ограничением инструмента тестирования; пользовательский выбор проверен в IAB.
