# MedPredict

Интерактивный прототип фронтенда дипломного проекта, часть Бөгенбаева Саната. React, TypeScript, Vite. Языки интерфейса — қазақша, русский и English; по умолчанию выбран русский. Сайт реализует путь от ввода показателей до результата и обработки ошибок.

**Это учебный прототип.** По умолчанию локальный запуск использует явно включённый деморежим. Значение 134,2 мм рт. ст. — фиксированный пример из запроса на разработку, а не вычисление нейросети. Окончательный показатель, модель и медицинские диапазоны не утверждены.

## Запуск

Нужен Node.js 22.12+ (проверено на 24.11.1) и npm.

```sh
npm ci
npm run dev
```

Открыть http://127.0.0.1:5173. Деморежим задан в `.env.development`; форма изначально пустая. Для проверки можно ввести: возраст 52, пол «Мужской», ИМТ 27,4, холестерин 5,6, глюкоза 5,9. Это синтетический пример.

## Режимы

```sh
cp .env.example .env.local
```

Измените `.env.local` и перезапустите Vite. Для сборки переменные задаются **до** `npm run build`: Vite встраивает их в браузерный код. Не помещайте секреты в `VITE_*`.

| Переменная | Значение |
|---|---|
| `VITE_API_MODE` | `demo` или `real`, обязательно |
| `VITE_DEMO_SCENARIO` | `success`, `validation` или `unavailable`; обязательно в demo |
| `VITE_API_BASE_URL` | Origin Spring Boot, например `http://localhost:8080`; пустое значение — тот же origin |
| `VITE_API_TIMEOUT_MS` | Таймаут API в мс, по умолчанию 15000 |

Для демонстрации ошибок поставьте `VITE_DEMO_SCENARIO=validation` или `unavailable`. Каждый запрос воспроизводит выбранный сценарий. Сценарий `validation` возвращает фиксированную ошибку возраста независимо от ввода; это не медицинская проверка. Для успешного сценария верните `success` и перезапустите приложение. Демо не отправляет сетевые запросы с показателями.

Для реального API:

```dotenv
VITE_API_MODE=real
VITE_API_BASE_URL=http://localhost:8080
VITE_API_TIMEOUT_MS=15000
```

Сначала выполняется `GET /api/v1/model/info`, затем `POST /api/v1/predictions`. Если описание полей недоступно или не соответствует контракту, форма блокируется и предлагает повторную загрузку. Никакого автоматического перехода в демо нет. Междоменный доступ требует CORS на Spring Boot; авторизация сейчас не входит в контракт.

В production нет режима по умолчанию: сборка без конфигурации покажет сообщение настройки, а не скрытую демонстрацию. Для просмотра демосборки сохраните `.env.local` с `VITE_API_MODE=demo` и `VITE_DEMO_SCENARIO=success`, затем:

```sh
npm run build
npm run preview
```

## Проверки

```sh
npm run typecheck
npm run lint
npm test
npm run build
npx playwright install chromium  # один раз, если Chromium ещё нет
npm run test:e2e
```

E2E запускают два временных локальных сервера и проверяют desktop 1440×1200 и mobile 390×844. В real-проекте Playwright подменяет ответы API; Java-сервер для этих тестов не нужен. Unit-тесты проверяют преобразование чисел, конфигурацию, ответы, отмену, таймаут и все три демосценария. Необходимые инструменты проверок находятся в devDependencies; зависимости приложения — React, React DOM и jsPDF (загружается при экспорте). Lockfile фиксирует установленные версии.

## Структура и решения

```text
src/pages/HomePage.tsx       главный экран и форма
src/components/             поле, результат, простые SVG-иконки
src/hooks/usePrediction.ts  загрузка метаданных и состояние запросов
src/config/                 показатель и окружение
src/i18n/                   словари kk/ru/en и перевод сообщений
src/api/                    HTTP, демо, ошибки, runtime-проверка контракта
src/types.ts                общие типы
src/validation.ts           преобразование и проверка ввода
src/pdf/                    текстовый шаблон A4 и генерация PDF
public/fonts/               локальный Noto Sans с лицензией OFL
tests/                      пользовательские браузерные сценарии
docs/                       контракт, путь пользователя, предзащита, дизайн
```

Один экран: маршрутизатор, UI-библиотека и менеджер глобального состояния не нужны. Нативные формы и select сохраняют клавиатурное управление. Типы TypeScript дополнены runtime-проверками сетевых ответов без отдельной библиотеки схем. Значения хранятся только в состоянии React; обновление страницы их очищает. HTTP использует `cache: no-store`, `credentials: omit` и не передаёт значения в URL. Политику хранения и журналирования на сервере должен определить Оралхан.

Демо-конфигурация — отдельный файл; в real поля, названия и точность задаёт GET. `decimalPlaces: null` отображает полученное число без дополнительного округления. Ограничения min/max/integer применяются только если сервер их возвращает. Клиентская проверка не заменяет серверную. В демо ноль, отрицательные и дробные значения допустимы технически, поскольку медицинские диапазоны не согласованы; это не означает их медицинскую корректность.

Переключатель языка в шапке переводит интерфейс, клиентские ошибки и поля демопримера, сохраняя введённые значения и текущий результат. Язык хранится в состоянии страницы, без localStorage/sessionStorage. В real подписи полей, единицы и произвольные сообщения сервера показываются как получены от API; их локализация требует согласования серверного контракта.

## Учебный проект и PDF

Нижний блок содержит исходный логотип MedPredict, официальный логотип AITU и подписи об учебном проекте студентов на русском и казахском. Обозначение не заявляет партнёрство, интеграцию или одобрение университетом. Исходник AITU сохранён без изменений из [официального сайта](https://astanait.edu.kz/assets/aitu-logo.svg), проверен 15 октября 2026. Шрифт [Noto Sans](https://github.com/notofonts/noto-fonts) хранится локально вместе с лицензией `public/fonts/OFL.txt`.

После валидного результата «Скачать PDF» формирует отдельный текстовый A4 и передаёт браузеру файл `medpredict-report-YYYY-MM-DD-HHmm.pdf`. Диалог печати не используется. При подготовке кнопка блокируется, при ошибке доступна повторная попытка. Папку и возможный диалог сохранения определяют настройки браузера.

Экспорт использует конкретный ответ и снимок проверенных данных отправленного запроса, без повторного POST. Изменение данных убирает результат и экспорт; уход с результата или переключение языка отменяет незавершённый экспорт. PDF содержит логотипы, подпись учебного проекта, дату формирования, показатель, введённые значения с единицами, результат, версию из ответа при наличии и дисклеймер. В демо явно отмечено, что модель не вызывалась. Отсутствующие необязательные поля не добавляются. Время прогноза не выводится: текущий согласуемый контракт его не предоставляет; дата формирования документа не подменяет время прогноза.

Язык PDF соответствует интерфейсу. В real подписи и единицы из API сохраняются как получены. Кириллица и казахские буквы поддерживаются встроенным Noto Sans, длинные строки переносятся; таблица продолжается на следующей странице с повтором заголовка. Загружаются только локальные шрифты и логотипы. Показатели не отправляются сторонним сервисам и не сохраняются интерфейсом; скачанный пользователем PDF содержит эти данные.
